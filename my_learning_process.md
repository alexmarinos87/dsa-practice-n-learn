# The Learning Process

For every exercise, I will follow this order:

    1. Define the input and output
    2. Write 2-3 examples
    3. Explain the algorithm in English
    4. Write pseudocode
    5. Implement in Python
    6. Implement in TypeScript
    7. Translate to Java
    8. State time and space complexity
    9. Retype from memory
    10. Try a relevant LeetCode problem
